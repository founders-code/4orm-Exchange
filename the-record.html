The record

Somebody asks about a deal from two years ago.

It arrives as an ordinary email and it names a file nobody remembers. Today that is two people off their job for a week, rebuilding a year from an inbox, a shared drive and somebody who has since left. Below is what comes back instead. Choose who is asking.

Who is asking
Targeted examination
File M-2291 · period requested, 1 Jan to 30 Jun 2024
Produced on request

The examiner is testing whether the file demonstrates that the recommendation suited that borrower. Not whether a form was completed.

  • What the borrower needed, as stated by them, on the date they stated it
  • The options considered, including the two that were declined and why
  • The recommendation and its reason, dated against what was known that day rather than what is known now
  • Material risks disclosed and acknowledged, with the time and the person
  • Every change, and the re-check that followed it
  • An index, so the examiner is reading a file rather than a folder
Assembled from records written as the work happened · nothing composed, nothing added
Customer complaint
File M-2291 · the borrower says the penalty was never explained
Answered from the file

A complaint is usually one person’s memory against another’s. This is the version where the file can speak.

  • What was disclosed about the penalty, in the words it was disclosed in
  • The acknowledgement, dated, and the copy the borrower received at the time
  • What the borrower said mattered to them before any product was discussed
  • The alternatives that were shown, which answers the question of whether a cheaper option existed

If the record shows the disclosure did not happen, it shows that too. This is not a tool for winning complaints. It is a tool for answering them from the file rather than from memory.

Supervision
Across everyone acting in the name of the firm
Two files open

The principal broker is accountable for work done by people they cannot watch. Deficiencies surface the day they occur instead of at the annual review.

  • Which files are incomplete right now, and precisely which item is missing from each
  • Which agent, so a pattern in one person’s files is visible before it becomes a pattern in the firm
  • How long it has been open, because a gap found on day two is a phone call and a gap found in month nineteen is a file that cannot be fixed

Handover
The agent who wrote this file has left the firm
Transfers with the file

The reasoning normally leaves when the person does, because it was never written down anywhere the firm owns. This is the case the platform quietly earns its keep on.

  • Why this product, so the next advisor is not guessing at a predecessor’s thinking
  • What the customer said mattered, so they are not asked to explain their life a second time
  • What is still outstanding, so nothing falls between two people
